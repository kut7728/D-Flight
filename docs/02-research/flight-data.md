# R-1. 항공 데이터 제공처

| 항목 | 내용 |
|---|---|
| 조사일 | 2026-10-12 |
| 방법 | 공식 가격표·API 명세·약관 확인. 가입하거나 키를 사용해 실제로 호출하지는 않았다. |
| 관련 기획 | F-02, F-04, F-05, 지원 범위 |

**(미검증)** 표시는 제3자 자료이거나 공식 페이지에서 확인하지 못한 내용이다.

## 1. 필요한 조건

- 편명과 날짜로 **몇 달 뒤 항공편**도 조회할 수 있어야 한다. 예매 직후 등록하기 때문이다.
- 출발·도착 터미널, 게이트, 체크인 카운터, 수하물 수취대를 제공해야 한다.
- 시각에 시간대 정보가 있어야 한다.
- **무료 공개 앱에서 상업적으로 사용**할 수 있고, 받은 데이터를 DB에 저장해 여러 사용자에게 보여 줄 수 있어야 한다.
- 월 운영비 목표 1,000엔 안에 들어와야 한다.

## 3. AeroDataBox 상세

- **가격**: API.market Pro $7.50/월 5,000 유닛, Pro 2 $15/월 15,000 유닛. 항공편 조회 1회 = **2 유닛**.
- **웹훅**: 구독 생성은 무료. 알림 1회에 항공편당 **1 유닛**. **출발 6시간 전 ~ 72시간 뒤** 범위의 항공편만 알림이 온다. 재시도가 기본으로 없어서(best-effort) 놓친 알림을 보완하는 조회가 필요하다.
- **실시간 정보 범위**: 실시간 데이터가 있는 공항만 상태가 갱신된다. 나머지는 시간표 정보만 나온다. 목표 공항(NRT, HND, KIX, ICN, GMP, PUS 등)의 실시간 지원 여부는 **가입 후 확인해야 한다.**
- **약관 핵심**
  - 상업적 사용은 **유료 요금제로 받은 데이터만** 허용된다.
  - 데이터 **캐시는 최대 7일**(또는 응답의 `max-age` 중 긴 쪽)까지 허용된다.
  - 원본 데이터를 재판매·재배포할 수 없다. **자기 앱 안에서 사용자에게 보여 주는 것은 허용**된다.
  - 항공 운항 업무용 표시에는 쓸 수 없다.

> **7일 캐시 제한의 영향**: '지난 항공편' 목록에 항공 데이터를 무기한 보관할 수 없다. 사용자가 입력한 편명·날짜만 남기고 항공 데이터 상세는 7일 뒤 지우는 방식이 필요하다. (04-technical에서 확정)

## 4. 갱신 전략별 호출량

가정: 사용자 100명 × 월 2편 = **월 200편**. 같은 항공편은 서버에서 한 번만 조회해 여러 사용자가 공유한다. 출발 30일 전 등록, 비행 3시간 기준.

| 구간 | A. 촘촘한 조회 | B. 줄인 조회 | **C. 조회 + 웹훅** |
|---|---|---|---|
| 등록 시 | 1 | 1 | 1 |
| ~ D-2 | 매일 (28) | 주 1회, D-7부터 매일 (8) | D-7, D-3 두 번 (2) |
| D-1 | 30분마다 (36) | 2시간마다 (9) | 웹훅 (0) |
| 출발 6시간 전 ~ 도착 | 10분마다 (60) | 15분마다 (26) | 웹훅 약 15회 (**가정**) |
| **항공편당** | 125회 | 44회 | 조회 3회 + 웹훅 약 15회 |
| **월 합계** | 25,000회 | 8,800회 | 조회 600회 + 웹훅 약 3,000회 |
| **AeroDataBox 요금** | $37.50 이상 | $37.50 | **약 4,200 유닛 → Pro $7.50** ✅ |

- 웹훅 횟수(항공편당 약 15회)는 추정치다. 테스트에서 실제 값을 측정해야 한다.
- 전략 C에서는 **출발 3일 전보다 이른 시점의 변경**(예: 한 달 전 시간표 변경)을 늦게 알게 된다. D-7, D-3 조회 때 감지한다.

## 5. 결론

1. 예산 안에 들어오는 유료 제공처는 **AeroDataBox Pro + 전략 C**뿐이다.
2. Pro $7.50은 **엔화로 약 1,100엔 이상**(환율 1달러 = 150엔 가정)이라 이것만으로 목표 1,000엔을 조금 넘는다.
3. 사용자가 늘어 월 200편을 넘으면 상위 요금제가 필요하다. 사용자별 등록 수 제한이나 호출 상한이 필요하다.
4. 인천공항 공공 API는 무료이고 정보도 풍부하지만 **인천 출발·도착, D-3 이후**만 다룬다. 비용 절감용 보조 데이터로 쓸 수 있다.
5. 일본 공항용 무료 공식 데이터는 찾지 못했다.
