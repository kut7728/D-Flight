# R-6. 항공 앱 아이콘

| 항목 | 내용 |
|---|---|
| 조사일 | 2026-10-12 |
| 방법 | App Store 아이콘 20개를 내려받아 직접 비교, Apple HIG 확인 |
| 관련 설계 | [시각 디자인](../03-design/visual-design.md) VD-06 |

## 1. 결론

- **처음 시안(네이비 + 오른쪽 위 흰 비행기 + 점선 곡선 궤적)은 FlightAware 아이콘과 구성이 거의 같다.** FlightAware의 브랜드 색도 진한 네이비(약 `#00153D`)다. 이 조합은 피한다.
- 비행기 실루엣은 항공 앱에서 가장 흔한 모티프다. 차별화 요소는 **'D' 글자**와 **D-Day(카운트다운)** 개념이다. 항공 추적 앱 중 글자 'D'나 카운트다운을 아이콘으로 쓰는 앱은 찾지 못했다.

| 앱 | 모티프 | 색 |
|---|---|---|
| Flighty | 3D 흰 여객기, 오른쪽 위 | 거의 검정 |
| **FlightAware** | **흰 비행기 오른쪽 위 + 점선 곡선 궤적** | **진한 네이비** |
| Flightradar24 | 레이더 원 | 파랑 그라데이션 |

| KAYAK | 흰 글자 'K' 하나 | 주황 |

## 3. 모티프별 혼잡도

| 모티프 | 상태 |
|---|---|
| 오른쪽 위 비행기 실루엣 | 매우 흔함 |
| 비행기 + 점선 궤적 | FlightAware 고유 → 피함 |
| 항공사 꼬리 날개·상징 | 상표 → 피함 |
| 레이더 | Flightradar24 계열 |
| 지구본·곡선 | 오래된 느낌 |
| 출발 전광판 (플립) | 비교적 드묾 |
| 탑승권 | 확인한 아이콘 중 없음 |
| 글자 하나 | KAYAK 사례. 항공 추적 앱 중 'D'는 없음 |
| 카운트다운·달력 | 확인한 아이콘 중 없음 |

## 4. Apple 가이드 요점 (HIG App icons)

- 최소한의 도형으로 단순하게. 작은 크기에서 세부가 사라진다.
- 글자는 피하되, **앱 이름 첫 글자는 허용**된다.
- 아주 얇은 선과 날카로운 모서리를 피한다. **점선은 작은 크기(29~40pt)에서 뭉개진다.**
- iOS 26: 배경 + 전경 레이어로 만들고 시스템이 Liquid Glass 효과를 입힌다. 직접 그림자·광택을 넣지 않는다.
- 6가지 모습(기본, 다크, 투명 라이트·다크, 틴트 라이트·다크)에서 모두 알아볼 수 있어야 한다. **틴트·투명 모드에서는 네이비가 사라지므로 모양만으로 구분돼야 한다.**

## 5. 주의할 점

- 특정 기종(보잉 747 혹 등)의 윤곽을 따라 그리지 않는다.
- 비행기는 관례상 **오른쪽 위(출발·진행)**를 향한다. 공식 규칙은 아니다.
- 글자 'D'는 굵고 모서리가 둥근 형태로 쓴다.

## 6. 권장

1. 'D'를 주인공으로 화면의 약 60% 크기로 그린다.
2. 점선 궤적을 빼거나, 쓴다면 큰 점 2~3개 또는 굵은 실선 하나로 바꾼다.
3. 비행기를 D에 통합한다. (D 안에 음각으로 뚫기 등)
4. 배경은 네이비 그라데이션, 포인트 색 하나(앰버 등)를 더해 FlightAware와 구분한다.
5. Icon Composer에서 6가지 모습과 작은 크기를 확인한 뒤 확정한다.

**검토한 대안**: A. D 안의 비행기(음각), B. D-Day 플립 타일, C. 탑승권 모양 D

## 7. 결정 (2026-10-12)

- **활주로 D**: 아이콘의 반 이상을 차지하는 흰 'D'를 활주로로 삼고, 그 곡선 위를 네이비 비행기가 달리며 뒤로 긴 점선 경로가 이어진다.
- 조사 권장 사항과의 관계: 'D'가 주인공(권장 1), 비행기를 D에 통합(권장 3). FlightAware(네이비 배경 위 흰 비행기 + 흰 점선)와 달리 비행기와 점선이 **흰 D 안의 네이비**라서 구성이 다르다.
- 남은 확인: 작은 크기(29~40pt)에서 비행기·점선이 보이는지, iOS 26 틴트·투명 모드에서 D 안의 비행기가 구분되는지. M2 최종 제작 때 Icon Composer로 확인한다.
