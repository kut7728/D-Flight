> 이 문서는 작성 방향을 정리한 것이며 법률 자문이 아니다. 아래 '확인 필요' 항목은 출시 전에 공식 자료로 확인한다.

|---|---|---|

- 문의 연락처: **앱 전용 새 이메일** (M9 전에 생성). 회사 이메일은 쓰지 않는다.

## 2. 개인정보 처리방침에 들어갈 내용

| 항목 | 내용 |
|---|---|
| 수집 항목 | 로그인 식별자, 이메일(Apple은 숨김 가능), 등록 항공편(편명·날짜), 앱 설정, 푸시 토큰, 사용자 제보와 작성 기록 |
| 수집하지 않는 것 | 이름, 예약번호, 좌석, 여권 정보, 위치, 연락처, 광고 식별자 |
| 이용 목적 | 항공편 정보 제공, 알림 발송, 제보 공유, 악용 방지 |
| 보관 기간 | 계정·등록 항공편: 삭제 시까지. 제보 작성 기록: 출발 후 30일. 푸시 토큰: 로그아웃·삭제 시까지 |
| 제3자 제공 | 없음. 사용자 제보 값(게이트 번호 등)은 같은 항공편 사용자에게 보이지만 작성자는 공개하지 않음 |
| 처리 위탁 | Google (Firebase: 인증, 데이터베이스, 서버, 푸시), Apple (푸시, 로그인) |
| 국외 이전 | 데이터는 일본(도쿄) Google Cloud에 저장. 위탁사 시스템 특성상 다른 국가에서 처리될 수 있음 |
| 이용자 권리 | 앱 안 계정 삭제, 이메일 문의 |
| 문의처 | 앱 전용 이메일 |

**확인 필요**
- 한국 개인정보 보호법: 개인정보 처리방침 필수 기재 항목, 국외 이전 고지 방식
- 일본 개인정보보호법: 외국 제3자 제공·위탁 고지
- 일본 전기통신사업법 외부 송신 규율: 이 앱이 적용 대상인지와 공표 방식

## 3. App Store 개인정보 라벨 (초안)

| 데이터 유형 | 수집 | 사용자 연결 | 추적 | 목적 |
|---|---|---|---|---|
| 연락처 정보 → 이메일 주소 | ✅ | ✅ | ❌ | 앱 기능 (계정) |
| 식별자 → 사용자 ID | ✅ | ✅ | ❌ | 앱 기능 |
| 식별자 → 기기 ID (푸시 토큰) | ✅ | ✅ | ❌ | 앱 기능 (알림) |
| 사용자 콘텐츠 → 기타 (등록 항공편, 제보) | ✅ | ✅ | ❌ | 앱 기능 |
| 위치, 연락처, 결제, 건강, 검색 기록, 광고 데이터 | ❌ | | | |

- **추적(Tracking) 없음.** 광고·분석 SDK를 넣지 않는다.
- Firebase SDK가 수집하는 항목은 사용하는 SDK 버전의 공식 안내로 M9에서 다시 확인한다.

## 4. 개인정보 매니페스트

- 앱과 위젯 타깃에 `PrivacyInfo.xcprivacy`를 넣는다.
- 사용하는 민감 API(예: `UserDefaults`)와 사용 이유를 신고한다.
- Firebase·GoogleSignIn SDK에 포함된 매니페스트를 확인한다.

## 5. 이용약관 주요 내용

- 항공편 정보는 **참고용**이며 정확성을 보장하지 않는다. 최종 정보는 항공사·공항 안내를 따른다.
- 정보 오류나 알림 지연으로 인한 손해에 책임지지 않는다. (각국 소비자 보호법 범위 안에서)
- 사용자 제보는 정해진 형식의 사실 정보만 입력한다. 고의로 틀린 정보를 입력하지 않는다.
- 서비스는 예고 없이 변경·중단될 수 있다.

## 6. 데이터 출처 표기

- 앱 설정 → 데이터 출처, App Store 설명, 지원 페이지에 표기한다.
- 표기: 인천국제공항공사, 한국공항공사 (공공데이터포털 data.go.kr)
- 각 API의 이용 조건(출처 표시 방식)을 활용 신청 화면에서 다시 확인한다.
