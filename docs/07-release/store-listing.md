## 3. 설명 (한국어 초안)

```
예매한 항공편을 등록해 두면 출발일까지 D-Day로 알려 드리고,
터미널·게이트·체크인 카운터·수하물 수취대를 한눈에 보여 드립니다.

■ 편명과 날짜만 입력하면 등록 끝
■ 출발 시각 변경·지연·결항, 게이트 배정·변경 알림
■ 출발 하루 전, 공항 출발 시간, 탑승 임박 알림
■ 잠금 화면 Live Activity와 홈 화면 D-Day 위젯
■ 공항 공식 안내도 바로가기
■ 코드쉐어 항공편은 실제 운항 항공사까지 안내
■ 한국어 · 日本語 · English

※ 자동 정보는 한국 공항(인천·김포 등) 공공 데이터를 사용합니다.
  다른 공항 정보는 같은 항공편 사용자의 제보로 채워집니다.
※ 항공편 정보는 참고용입니다. 최종 정보는 항공사와 공항 안내를 확인해 주세요.

데이터 출처: 인천국제공항공사, 한국공항공사 (공공데이터포털)
```

일본어·영어 설명은 한국어 확정 후 번역한다.

## 5. 스크린샷

- **가상 데이터(Mock 빌드)**로만 만든다. 실제 여행 정보를 쓰지 않는다.

## 6. 심사 메모 (App Review Information)

로그인이 필수이고, 실제 항공편이 있어야 기능을 볼 수 있으므로 심사자에게 안내를 남긴다.

```
- Sign in with Apple 또는 Google로 로그인할 수 있습니다.
- 기능 확인: 인천공항(ICN)에서 오늘 또는 내일 출발하는 아무 항공편이나
  편명과 날짜로 등록하면 터미널·게이트 정보와 갱신을 볼 수 있습니다.
- 한국 공항이 없는 항공편은 '직접 입력 등록'으로 등록되며,
  사용자 제보는 형식이 정해진 값(게이트 번호 등)만 받습니다.
- 계정 삭제: 설정 → 계정 → 계정 삭제
```

- 심사용 Google 테스트 계정이 필요하면 앱 전용으로 만들고, 비밀번호는 App Store Connect 입력란에만 넣는다. (저장소·문서에 기록하지 않음)
- 심사 메모는 영어로 작성한다.
