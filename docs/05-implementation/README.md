M4의 실기기 검증은 남아 있다. `DFlight` 스킴에서 인천 출발·도착편을 각각 등록해 터미널·게이트(배정된 경우)가 표시되고 주기 갱신이 반영되는지 확인한다. 실제 서버의 오프라인 캐시·복귀도 확인한다. 통과 후 사용자가 검토하기 전에는 M5로 넘어가지 않는다.

구현 제한은 [데이터 갱신과 알림](../04-technical/data-sync.md)의 M4 구현 제한에 기록했다.

## 진행 규칙

- 한 번에 한 마일스톤만 진행한다.
- 실제 키·토큰은 채팅·저장소·문서·로그에 남기지 않는다.
- 설계와 다르게 구현해야 하면 먼저 문서를 고치고 사용자와 결정한다.
- 미구현 기능을 완료로 문서에 쓰지 않는다.
