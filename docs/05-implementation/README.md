| # | 결정 |
|---|---|
| IM-01 | **새 저장소**에서 시작한다. 현재 폴더(이전 코드·문서)는 그대로 두고 참고용으로 남긴다. 이 `docs/`는 새 저장소로 옮긴다. |

| IM-05 | 핵심 기능(M6까지)을 위젯·Live Activity(M7, M8)보다 먼저 만든다. |
| IM-06 | 한국공항공사 실시간은 **조회(15158625)** 와 **검색(15160195)** 을 모두 신청한다. 공항·날짜 묶음 조회는 조회 API를 우선 검증한다. |
| IM-07 | 앱 번들 ID는 `com.dflight`, 위젯은 `com.dflight.widgets`, App Group은 `group.com.dflight` |
