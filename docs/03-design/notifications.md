# 알림·위젯·Live Activity

문구는 한국어 기준이다. 일본어·영어 번역은 구현 단계에서 만든다. 푸시 알림은 사용자가 고른 앱 언어로 보낸다.

## 1. 변경 알림 (F-05, 서버가 보냄)

공항 데이터에서 감지한 변경만 보낸다. 사용자 제보로 바뀐 값은 알리지 않는다.

| 종류 | 제목 | 본문 예시 |
|---|---|---|
| 출발 시각 변경·지연 | NH5701 출발 지연 | 출발이 10:00 → 10:45(현지)로 변경되었습니다. |
| 결항 | NH5701 결항 | 항공편이 결항되었습니다. 항공사에 확인해 주세요. |
| 터미널 변경 | NH5701 터미널 변경 | 출발 터미널이 T2 → T1로 변경되었습니다. |
| 게이트 배정 | NH5701 게이트 안내 | 출발 게이트가 108번으로 정해졌습니다. |
| 게이트 변경 | NH5701 게이트 변경 | 출발 게이트가 108 → 112번으로 변경되었습니다. |
| 도착 시각 변경 | NH5701 도착 시각 변경 | 도착이 13:15 → 13:40(현지)로 변경되었습니다. |
| 수하물 수취대 배정 | NH5701 수하물 수취대 | 수하물은 12번 수취대에서 찾을 수 있습니다. |

- 짧은 시간에 여러 변경이 생기면 **한 알림으로 묶는다.** (예: 게이트·시각 동시 변경)
- 알림을 누르면 해당 항공편 상세(S-06)로 간다.

## 2. 시간 임박 알림 (F-06, 기기에서 예약)

| 종류 | 시점 (고정) | 본문 예시 |
|---|---|---|
| 하루 전 | 24시간 전 | 내일 10:45 하네다(HND)에서 NH5701이 출발합니다. |
| 공항 출발 | 3시간 전 | 공항으로 출발할 시간입니다. 출발 터미널 T3 |
| 탑승 임박 | 40분 전 | 곧 탑승이 시작됩니다(추정). 게이트 108 |

- 항공편마다 변경 알림·임박 알림 3종을 켜고 끈다 (기본 모두 켜짐). 설정의 앱 알림을 끄면 모두 울리지 않는다. (DS-16)
- 출발 시각이 바뀌면 바뀐 시각 기준으로 다시 예약한다.
- 터미널·게이트를 모르면 해당 부분을 빼고 보낸다.
- 결항된 항공편은 임박 알림을 취소한다.

## 3. 위젯 (F-08)

| 크기 | 내용 |
|---|---|
| 작은 위젯 | `D-3`, `HND → ICN`, 편명 |
| 중간 위젯 | 위 내용 + 출발 날짜·시각, 출발 터미널·게이트, 상태 |
| 잠금 화면 위젯 | `D-3 · HND→ICN` 한 줄 |

```
작은 위젯          중간 위젯
┌────────┐       ┌──────────────────┐
│ D-3    │       │ D-3     NH5701   │
│ HND→ICN│       │ HND → ICN        │
│ NH5701 │       │ 11/01 10:45 지연  │
└────────┘       │ T3 · 게이트 미정   │
                 └──────────────────┘
```

| 상태 | 표시 |
|---|---|
| 항공편 없음 | '등록된 항공편 없음' |
| 로그아웃 | 'D-Flight에 로그인하세요' |
| 출발 당일 | D-Day 대신 출발까지 남은 시간 |

## 4. Live Activity (F-09)

**시작·종료**

| 항목 | 규칙 |
|---|---|
| 시작 | 출발 3시간 전 서버가 자동 시작. 설정에서 끄면 시작하지 않는다. |
| 갱신 | 출발 시각, 상태, 터미널, 게이트가 바뀔 때 |
| 종료 | 도착하면 종료. 최대 8시간 제한으로 장거리 항공편은 도중에 끝난다. 결항이면 결항 표시 후 종료 |
| 여러 항공편 | 시간이 겹치면 먼저 출발하는 항공편만 표시 |

**잠금 화면**

```
┌──────────────────────────────┐
│ ✈ NH5701  HND → ICN    지연    │
│ 출발 10:45 (현지)  · 1:20 남음   │
│ 터미널 T3        게이트 108     │
└──────────────────────────────┘
```

**다이내믹 아일랜드**

| 형태 | 내용 |
|---|---|
| 작게 (좌/우) | ✈ 아이콘 / `G108` 또는 `1:20` |
| 펼침 | 잠금 화면과 같은 내용 |
| 최소 | ✈ 아이콘 |
