# 화면별 상세

표시 규칙(시각, 상태, 출처 등)은 [정보 표시 규칙](display-rules.md)을 따른다.

---

## S-01 로그인

```
┌──────────────────────────┐
│                          │
│        D-Flight          │
│  예매한 비행기, 놓치지 않게  │
│                          │
│  [  Apple로 계속하기  ]    │
│  [  Google로 계속하기 ]    │
│                          │
│  개인정보 처리방침 · 이용약관 │
└──────────────────────────┘
```

| 항목 | 내용 |
|---|---|
| 버튼 | Apple, Google 로그인. 각 회사의 공식 버튼 지침을 따른다. |
| 실패 | 취소하면 조용히 원래 화면. 오류면 '로그인하지 못했습니다. 다시 시도해 주세요.' |
| 하단 | 개인정보 처리방침, 이용약관 링크 |

## S-02 알림 허용 안내

```
┌──────────────────────────┐
│         🔔               │
│  게이트가 바뀌면 바로 알려   │
│  드릴게요                 │
│                          │
│  · 출발 시각 변경·결항      │
│  · 터미널·게이트 변경       │
│  · 출발 24시간·3시간 전     │
│                          │
│  [ 알림 허용 ]             │
│    나중에                  │
└──────────────────────────┘
```

- '알림 허용'을 누르면 iOS 권한 창을 띄운다. iOS 권한 창은 앱당 한 번만 뜨므로 이 안내 화면을 먼저 보여 준다.
- '나중에'를 누르면 S-03으로 간다.

## S-03 내 항공편 (탭 1)

```
┌──────────────────────────┐
│ 내 항공편              [+] │
├──────────────────────────┤
│ ┌──────────────────────┐ │
│ │ D-3        지연 45분   │ │
│ │ NH5701                │ │
│ │ 하네다 HND → 인천 ICN   │ │
│ │ 11/01 (토) 10:45 출발   │ │
│ │ 터미널 T3 · 게이트 미정  │ │
│ └──────────────────────┘ │
│                          │
│ 다가오는 항공편             │
│  D-20  KE712  ICN → NRT  │
│  D-45  JL91   HND → GMP  │
└──────────────────────────┘
│ [내 항공편] [지난 항공편] [설정] │
```

| 영역 | 내용 |
|---|---|
| 큰 카드 | 가장 가까운 항공편. D-Day, 상태, 편명, 노선, 출발 날짜·시각, 출발 터미널·게이트. 가로는 아래 목록과 같은 좌우 여백으로 꽉 채운다 (DS-12) |
| 목록 | 나머지 다가오는 항공편. D-Day, 편명, 노선 |
| + 버튼 | S-04 등록 시트 |
| 당겨서 새로고침 | 서버 DB의 최신 값을 다시 받는다. (외부 API를 직접 부르지 않음) |
| 밀어서 삭제 | 확인 창 후 삭제 |

**상태별 화면**

| 상태 | 표시 |
|---|---|
| 항공편 없음 | '등록된 항공편이 없습니다' + [항공편 등록] 버튼 |
| 알림 꺼짐 | 상단 배너 '알림이 꺼져 있어 변경을 알려 드릴 수 없습니다 · 설정 열기' |
| 오프라인 | 상단 배너 '오프라인 · 마지막 갱신 10:30'. 저장된 값으로 표시 |

## S-04 항공편 등록

**1단계: 입력**

```
┌──────────────────────────┐
│ 취소     항공편 등록        │
├──────────────────────────┤
│ 편명                      │
│ [ NH5701              ]  │
│ 출발 날짜 (출발 공항 기준)  │
│ [ 2026-11-01          ]  │
│                          │
│ [        찾기         ]   │
└──────────────────────────┘
```

| 항목 | 규칙 |
|---|---|
| 편명 | 항공사 코드 2~3자 + 숫자 1~4자리. 소문자는 대문자로 자동 변환. 공백 제거 |
| 출발 날짜 | 오늘 ~ 1년 뒤. **출발 공항 현지 날짜**라고 안내한다. (시차 때문에 기기 날짜와 다를 수 있음) |

**2단계: 결과**

| 결과 | 동작 |
|---|---|
| 1건 찾음 | 노선, 시각, 실제 운항 항공사를 보여 주고 [등록] 버튼 |
| 여러 건 | 같은 편명이 하루 여러 구간을 운항할 때. 구간을 고르게 한다. |
| 다른 사용자가 등록한 항공편 | 공유된 제보 정보와 함께 보여 주고 [등록] |
| 못 찾음 | '자동 정보를 찾지 못했습니다' + 이유 안내 + [직접 입력해서 등록] → S-05 |
| 이미 등록함 | '이미 등록된 항공편입니다' + [보기] → S-06 |
| 검색 실패 (네트워크·서버) | '지금은 확인할 수 없습니다. 잠시 후 다시 시도해 주세요.' |

'못 찾음'일 때 이유 안내:
- 한국 공항이 포함되지 않은 항공편은 자동 정보를 지원하지 않는다.
- 편명이나 날짜가 잘못됐을 수 있다.

## S-05 직접 입력 등록

S-04에서 못 찾았을 때 이동한다. 입력한 정보는 같은 항공편을 등록한 다른 사용자와 공유된다고 **입력 전에 안내**한다.

| 항목 | 필수 | 입력 방식 |
|---|---|---|
| 편명, 출발 날짜 | ✅ | S-04 값 그대로 (수정 불가) |
| 출발 공항, 도착 공항 | ✅ | 공항 검색 목록에서 선택 |
| 출발 예정 시각 | ✅ | 시각 선택기 (출발 공항 현지 시각) |
| 도착 예정 시각 | | 시각 선택기 (도착 공항 현지 시각, 날짜 차이 선택) |
| 터미널, 게이트, 체크인 카운터, 수하물 수취대 | | S-07과 같은 형식 |

## S-06 항공편 상세

```
┌──────────────────────────────────┐
│ ‹ 내 항공편              공유  ⋯  │
├──────────────────────────────────┤
│ ✈ XX5701  HND → ICN       지연    │  ← 상태 배너 (다이내믹 아일랜드 펼침과 같은 내용)
│ 출발 10:45 (현지)  · D-3          │
│ 터미널 T3          게이트 미정       │
│ 샘플 데이터 · 실제 운항: YY1075 — 체크인은 YY항공 │
├──────────────────────────────────┤
│ 출발 · 하네다 (HND)            ✏️ │  ← 머리 행 (52pt, 18pt 굵게), 오른쪽 끝 편집
│ 출발                 ~~10:00~~ 10:45 │  ← 정보 행 (48pt 고정)
│ 터미널          [사용자 제보]    T3 │
│ 체크인                    정보 없음 │
│ 게이트                        미정 │
│ 공항 안내도              지도에서 열기 │  ← 텍스트 버튼
├──────────────────────────────────┤
│ 도착 · 인천 (ICN)          현지 시각 │
│ 도착                         13:40 │
│ 터미널                          T1 │
│ 게이트                  [변경]  25 │
│ 수하물                        미정 │
├──────────────────────────────────┤
│ 출처: 인천국제공항공사 · 10:30 기준  │
└──────────────────────────────────┘
```

**행 규칙**
- 모든 정보 행은 **같은 높이(48pt)**. 칩이 있어도 줄이 늘어나지 않는다.
- 출발·도착 **머리 행은 조금 더 높고(52pt) 글자가 조금 더 크다(18pt 굵게).**
- **값과 변경 전 값은 오른쪽 끝**에 붙인다. 순서: `변경 전 값(취소선)` → `값`
- **`사용자 제보`·`변경` 칩은 값의 왼쪽**에 둔다. 행마다 `제보하기` 버튼은 두지 않는다. 제보는 머리 행 오른쪽 끝 **편집(연필) 아이콘**으로 한다 (DS-15).
- 탑승 시작(추정)은 홈 탑승권 카드에만 보여 준다.

| 영역 | 내용 |
|---|---|
| 상단 상태 배너 | **다이내믹 아일랜드 펼침(=Live Activity 잠금 화면)과 같은 내용**: 편명·노선·상태 / 출발 시각(현지)·남은 시간 / 터미널·게이트. 가로로 꽉 채운다. 배너 아래쪽 한 줄에 `샘플 데이터` 칩, 코드쉐어 안내, 결항 안내를 작게 둔다 (DS-13) |
| 남은 시간 | 출발 24시간 전까지는 `D-n`, 24시간 안이면 `1:20 남음`, 출발 후에는 상태(`출발함`·`도착함`) (DS-13) |
| 당겨서 새로고침 | 서버 DB의 최신 값을 다시 읽는다. 외부 API를 부르지 않는다 (DS-14) |
| 출발·도착 | 공항, 시각, 터미널, 게이트, 체크인 카운터(출발), 수하물 수취대(도착), 항목별 출처 |
| 공항 안내도 | 해당 공항·터미널 공식 안내도를 S-10으로 연다. 주소가 없으면 버튼을 숨긴다. 텍스트 버튼 |
| 지도에서 열기 | Apple 지도 / Google 지도 중 선택. 텍스트 버튼 |
| 공유 | iOS 공유 시트로 텍스트 전송 (F-10) |
| 알림 버튼 (툴바 🔔) | 누르면 드롭다운 메뉴로 이 항공편의 알림 4종(변경 알림, 출발 24시간 전, 출발 3시간 전, 탑승 임박)을 켜고 끈다. 기본은 모두 켜짐. 설정의 앱 알림이 꺼져 있으면 메뉴 위에 안내를 둔다 (DS-16) |
| ⋯ 메뉴 | 정보 제보·수정, 항공편 삭제 |
| 정보 제보·수정 | 출발·도착 머리 행의 편집 아이콘(해당 쪽) 또는 ⋯ 메뉴 → S-07. 공항 데이터가 없는 항목만 수정할 수 있다. |
| 하단 | 데이터 출처와 마지막 갱신 시각 |

**공유 텍스트 예시**
```
✈ NH5701 (운항 OZ1075)
하네다 HND 11/01 10:45 → 인천 ICN 13:15 (현지 시각)
출발 터미널 T3 · 게이트 미정
D-Flight
```

**결항일 때**: 상단에 '결항되었습니다. 항공사에 확인해 주세요.' 강조. 터미널·게이트는 흐리게 표시한다.

**지난 항공편(S-08)에서 열었을 때**: 읽기 전용. 편집 아이콘·제보 메뉴·알림 버튼을 숨긴다.

## S-07 정보 제보·수정

```
┌──────────────────────────┐
│ 취소   정보 제보     저장   │
├──────────────────────────┤
│ 입력한 정보는 같은 항공편을   │
│ 등록한 사용자에게 공유됩니다. │
│                          │
│ 출발 · 하네다 (HND)         │
│  터미널    [ T3 ▾ ]        │
│  체크인    [ K  ]          │
│  게이트    [ 108 ]         │
│ 도착 · 인천 (ICN)           │
│  (공항 데이터로 제공 중)      │
└──────────────────────────┘
```

| 항목 | 입력 형식 |
|---|---|
| 터미널 | 목록 선택. 공항별 터미널 목록이 없으면 `T1`~`T9` 등 정해진 값 중 선택 |
| 게이트 | 영문·숫자 1~5자. 예: `108`, `C24`, `52A` |
| 체크인 카운터 | 영문·숫자·`-` 1~7자. 예: `K`, `A-C`, `L10-15` |
| 수하물 수취대 | 영문·숫자 1~3자 |
| 시각 | 시각 선택기 |

- **공항 데이터로 받은 항목은 수정할 수 없다.** (API 우선 원칙)
- 값 지우기를 허용한다. (잘못된 제보 정정)
- 저장하면 공유 정보가 바로 바뀐다. 다른 사용자에게 알림은 보내지 않는다.

## S-08 지난 항공편 (탭 2)

- 최근 출발 순으로 목록 표시. 편명, 노선, 날짜.
- 항목을 누르면 S-06 읽기 전용.
- 밀어서 삭제.
- 없으면 '지난 항공편이 없습니다'.

## S-09 설정 (탭 3)

| 그룹 | 항목 |
|---|---|
| 화면·언어 | **화면 모드: 시스템 / 라이트 / 다크** (드롭다운), **언어** (드롭다운). 한 그룹에 함께 둔다 (DS-17) |
| 알림 | **앱 알림 켜기/끄기** 하나만 둔다. 끄면 항공편별 설정과 관계없이 모든 알림이 울리지 않는다. 항공편별 4종은 상세 화면 알림 버튼에서 정한다 (DS-16) |
| | iOS 알림 권한이 꺼져 있으면 '설정 앱에서 켜기' 안내 |
| 잠금 화면 | Live Activity 자동 시작 켜기/끄기 |
| 일반 | **공지사항** (읽지 않은 수 빨간 점) → S-11 |
| 계정 | 로그인 방식(Apple / Google), 로그아웃, **계정 삭제** |
| 정보 | 데이터 출처, 자동 정보 지원 공항 안내, 개인정보 처리방침, 이용약관, 문의하기, 앱 버전 |

**화면 모드 전환**
- 선택 즉시 앱 전체가 **약 0.4초 동안 부드럽게 색이 바뀐다.** (화면 전체 크로스페이드)
- 선택은 기기에만 저장한다. (기기마다 다를 수 있는 취향이므로 서버에 저장하지 않음)
- 시스템을 고르면 iOS 설정을 따른다.

**임박 알림 시점** — 고정이다. 사용자가 바꿀 수 없다 (DS-16)

| 알림 | 시점 |
|---|---|
| 하루 전 | 출발 24시간 전 |
| 공항 출발 | 출발 3시간 전 |
| 탑승 임박 | 출발 40분 전 |

**계정 삭제 흐름**

```
계정 삭제 누름
  ▼
확인 창: '등록한 항공편과 설정이 모두 삭제되며 되돌릴 수 없습니다.'
  ▼ 삭제
(Apple 로그인 사용자) Apple 재인증 → 토큰 해지
  ▼
서버 데이터 삭제 → 기기 데이터 삭제 → S-01 로그인
```

- 내가 한 **사용자 제보는 남기되 작성자 정보는 지운다.** 다른 사용자가 쓰는 공유 정보이기 때문이다. (04-technical에서 확정)

## S-10 공항 안내도

- 앱 안 브라우저(Safari 화면)로 공항 공식 안내도를 연다.
- 앱 언어와 같은 언어 페이지가 있으면 그 페이지를 연다.
- 안내도 이미지를 앱에 저장하지 않는다.

---

## S-11 공지사항

- 설정 → 공지사항에서 목록으로 본다. 최신순. 제목, 날짜, 읽음 여부(빨간 점).
- 누르면 상세(제목, 날짜, 본문). 본문은 텍스트와 링크만.
- 앱 언어로 보여 준다. 해당 언어가 없으면 영어 → 한국어 순으로 대신한다.
- 읽음 여부는 기기에 저장한다.
- 공지가 없으면 '공지사항이 없습니다'.

**중요 공지 팝업**
- `중요`로 표시된 공지 중 아직 안 본 것을 앱 실행 시 **한 번** 알림 창으로 보여 준다. 여러 개면 최신 1개만.
- [확인]을 누르면 읽음 처리. 다시 띄우지 않는다.


## S-12 강제 업데이트

- 앱 버전이 서버의 **최소 버전**보다 낮으면 보여 준다. **닫거나 뒤로 갈 수 없다.**
- 앱 아이콘, '업데이트가 필요합니다', 짧은 설명, [App Store에서 업데이트] 버튼.
- 버튼은 App Store의 앱 페이지를 연다.
- 앱이 백그라운드에서 돌아올 때도 다시 확인한다.
