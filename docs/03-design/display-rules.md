# 정보 표시 규칙

모든 화면, 위젯, Live Activity, 알림에 공통으로 적용한다.

## 1. 시각

- 출발 시각은 **출발 공항 현지 시각**, 도착 시각은 **도착 공항 현지 시각**으로 표시한다.
- 출발·도착 공항의 시간대가 다르면 시각 옆에 `현지` 표시를 붙인다.
- 도착 날짜가 출발 날짜와 다르면 `+1`처럼 날짜 차이를 붙인다.
- 시각이 바뀌면 **변경된 시각을 크게**, 원래 시각을 작게 취소선으로 보여 준다.

```
출발  10:00 → 10:45   (지연 45분)
      ~~10:00~~
```

## 2. D-Day

- **출발 공항 현지 날짜** 기준으로 계산한다.
- 표시: `D-12`, `D-1`, `D-Day`(당일)
- 출발 후에는 D-Day 대신 상태를 표시한다. (`출발함`, `도착함`)

## 3. 항공편 상태

| 상태 | 표시 | 강조 |
|---|---|---|
| 예정 | 예정 | 기본 |
| 지연 | 지연 | 주의 |
| 결항 | 결항 | 위험 |
| 출발함 | 출발함 | 기본 |
| 도착함 | 도착함 | 기본 |
| 알 수 없음 | 상태 정보 없음 | 약하게 |

색만으로 구분하지 않고 **글자를 항상 함께** 보여 준다. (색각 이상 사용자 배려)

## 4. 정보 항목별 상태

터미널, 게이트, 체크인 카운터, 수하물 수취대, 시각마다 아래 중 하나로 표시한다.

| 상태 | 의미 | 표시 예 |
|---|---|---|
| 확정 (공항 데이터) | 공공 API에서 받은 값 | `T2` |
| 확정 (사용자 제보) | 다른 사용자가 입력한 값 | `T2` + `사용자 제보` 표시 |
| 미정 | 자동 정보 지원 공항이지만 아직 배정 전 | `미정` |
| 정보 대기 | 자동 정보가 들어오기 전 (인천 D-3 이전 등) | `출발 3일 전부터 표시` |
| 자동 정보 없음 | 자동 정보를 지원하지 않는 공항이고 제보도 없음 | `정보 없음 · 제보하기` |
| 확인 실패 | 서버가 최근 갱신에 실패함 | 마지막 값 + `확인 실패` (마지막 갱신 시각은 화면 하단 출처에만) |

- 항목마다 **출처**와 **마지막 갱신 시각**을 상세 화면에 표시한다.
- 사용자 제보 값이 바뀌어도 '변경됨' 강조는 하지 않는다. 공항 데이터로 바뀐 값만 강조한다.

## 5. 코드쉐어

사용자가 입력한 편명을 제목으로 보여 주고, 실제 운항 편명을 그 아래에 강조한다.

```
NH5701
✈ 실제 운항: 아시아나항공 OZ1075
  체크인은 아시아나항공 카운터에서 합니다.
```

## 6. 공항 표기

- `공항 이름 (코드)` 형식. 예: `인천 (ICN)`, `하네다 (HND)`
- 좁은 곳(위젯, 다이내믹 아일랜드)에서는 코드만 쓴다.

## 7. 탑승 시각

API가 탑승 시각을 주지 않으므로 화면에 표시할 때 항상 `탑승 시작 약 09:20 (추정)`처럼 **추정**을 붙인다. 계산 기준은 출발 40분 전이다.
