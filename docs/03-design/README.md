## 결정 사항 (2026-10-12)

| # | 결정 |
|---|---|
| DS-01 | 하단 탭 3개: **내 항공편 / 지난 항공편 / 설정** |
| DS-02 | 내 항공편 탭: **가장 가까운 항공편 큰 카드 + 아래 목록** |
| DS-03 | 시각은 **각 공항의 현지 시각**으로 표시한다. |
| DS-04 | 코드쉐어: **입력한 편명**을 보여 주고 **실제 운항 편명**을 함께 강조한다. |
| DS-05 | Live Activity는 **출발 3시간 전 자동 시작**. 설정에서 끌 수 있다. |
| DS-06 | 언어는 **앱 안 설정 메뉴**에서 고른다(기기 언어 따르기 / 한국어 / 日本語 / English). 서버 푸시 문구도 선택한 언어로 보낸다. |
| DS-07 | 화면 설계 산출물은 **문서 + 텍스트 스케치**. 시각 디자인은 문서 + HTML 미리보기 (VD-01~07) |
| DS-08 | 설정에서 **화면 모드(시스템·라이트·다크)** 선택, 바꿀 때 화면 전체 크로스페이드 애니메이션. 기기에만 저장 |
| DS-09 | **공지사항**: 설정에 목록(S-11), 중요 공지만 앱 실행 시 1회 팝업 |
| DS-10 | **강제 업데이트**: 최소 버전 미만이면 닫을 수 없는 업데이트 화면(S-12). 권장 업데이트 없음. 확인 실패 시 막지 않음 |
| DS-11 | 상세 화면 정보 행 높이 통일(48pt), 머리 행 52pt·18pt. 값은 오른쪽 끝, 칩·버튼은 값 왼쪽 |

## 기본값으로 정한 항목 (확정, 운영하며 조정 가능)

일반적인 기준으로 정했고 2026-10-12에 함께 확정했다.

| 항목 | 기본값 |
|---|---|
| 지난 항공편으로 옮기는 시점 | 도착 시각 + 3시간. 도착 시각을 모르면 출발 시각 + 24시간 |
| 등록할 수 있는 날짜 | 오늘 ~ 1년 뒤. 지난 날짜는 등록할 수 없다. |
| 등록된 항공편 날짜 수정 | 수정하지 않고 삭제 후 다시 등록한다. |
| 기기 언어가 한·일·영이 아닐 때 | 영어로 표시 |
| 항공편 삭제 | 목록에서 밀어서 삭제 + 확인 창 |
