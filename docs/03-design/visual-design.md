## 1. 방향

> **딥 네이비 + 화이트, 항공사처럼 차분하고 믿음직하게.** 화면은 iOS 기본 요소를 쓰고, 앱의 개성은 **탑승권 모양 항공편 카드**에 모은다.

| 결정 | 내용 |
|---|---|
| VD-01 | 메인 색 **딥 네이비**, 배경 화이트(라이트)·블랙(다크) |
| VD-02 | 라이트·다크 모드 **모두 지원** (시스템 설정 따름) |
| VD-03 | 탭 바·목록·설정·시트·버튼은 **iOS 기본 요소**. iOS 26에서는 Liquid Glass가 자동 적용된다. |
| VD-04 | 홈의 가장 가까운 항공편은 **탑승권 모양 카드**. 라이트 모드 화이트, 다크 모드 네이비 (아이보리는 검토 후 제외) |
| VD-05 | 숫자는 **SF Pro 굵게 + 고정폭 숫자** |
| VD-06 | 앱 아이콘: 네이비 배경 + **활주로가 된 큰 'D'**, 그 곡선 위를 달리는 비행기와 긴 점선 이동 경로 |
| VD-07 | 산출물: 이 문서 + HTML 미리보기 |
| VD-08 | 아이콘 레이어 SVG는 Claude, Icon Composer 조립은 사용자 (M2, 2026-10-12) |

## 2. 색

### 브랜드·기본

| 이름 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `brandNavy` | `#0B2545` | `#14305A` | 다크 모드 카드 배경, 위젯, 앱 아이콘 |
| 카드 (라이트) | `#FFFFFF` | — | **라이트 모드** 탑승권·요약 카드 배경. 글자는 네이비 |
| `accent` | `#1E4B8F` | `#8AB8FF` | 버튼, 링크, 선택 상태 (앱 tint) |
| 배경 | 시스템 `systemGroupedBackground` | 같음 | 화면 배경 |
| 표면 | 시스템 `secondarySystemGroupedBackground` | 같음 | 목록 행, 상세 카드 |
| 글자 | 시스템 `label` / `secondaryLabel` | 같음 | 본문 |

다크 모드 카드는 검은 배경과 구분되도록 조금 밝은 네이비를 쓴다.

### 상태 색

| 상태 | 일반 화면 (라이트 / 다크) | 카드 위 (화이트 / 네이비) |
|---|---|---|
| 지연·변경 | `#B45309` / `#FBBF24` | `#B45309` / `#FCD34D` |
| 결항 | `#B91C1C` / `#F87171` | `#B91C1C` / `#FCA5A5` |
| 정상·예정 | `secondaryLabel` | `#6B7280` / 흰색 72% |

- 상태는 **색 + 글자**로 함께 표시한다. ([표시 규칙](display-rules.md#3-항공편-상태))
- 정상 상태에 초록색을 쓰지 않는다. 항공편은 대부분 정상이라 강조할 필요가 없고, 지연·결항만 눈에 띄게 한다.

## 3. 글자

iOS 기본 글꼴(SF Pro, 한국어·일본어는 시스템 글꼴)만 쓴다. **다이내믹 타입**(사용자 글자 크기 설정)을 따른다.

| 용도 | SwiftUI 스타일 | 예 |
|---|---|---|
| 화면 제목 | `.largeTitle` bold | 내 항공편 |
| 카드 공항 코드 | `.largeTitle` bold, 고정폭 숫자 | HND → ICN |
| 핵심 숫자 (게이트·터미널·시각) | `.title2` bold, 고정폭 숫자 | 108, 10:45 |
| D-Day | `.headline` bold | D-3 |
| 항목 이름 | `.subheadline` | 게이트 |
| 본문 | `.body` | |
| 보조 정보 (출처, 갱신 시각) | `.footnote` / `.caption` secondary | 10:30 기준 |

- 숫자에는 `.monospacedDigit()`을 붙여 남은 시간이 바뀔 때 글자가 흔들리지 않게 한다.
- 큰 글자 설정(접근성 크기)에서는 카드 안 가로 배치를 세로로 바꾼다.

## 5. 탑승권 카드 (S-03 큰 카드)

```
╭──────────────────────────────────╮
│ D-3                    지연 45분   │  ← 상단: D-Day, 상태
│ XX5701 · 실제 운항 YY1075          │
│                                  │
│ HND  ───── ✈ ─────  ICN          │  ← 공항 코드 크게
│ 하네다              인천            │
│ 11/1(토) 10:45      13:15 현지     │
◖ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ◗  ← 절취선 + 양쪽 반원 홈
│ 터미널      게이트      탑승 시작     │  ← 하단: 공항에서 볼 정보
│ T3         미정        10:05 추정   │
╰──────────────────────────────────╯
```

| 영역 | 규칙 |
|---|---|
| 배경 | 라이트 모드 **화이트**(글자 네이비), 다크 모드 **네이비**(`brandNavy`). 그림자 없이 평평하게 |
| 상단 | D-Day(왼쪽), 상태(오른쪽, 정상이면 숨김) |
| 가운데 | 출발·도착 공항 코드, 공항 이름, 현지 시각. 변경된 시각은 지연 색 |
| 절취선 | 점선 + 양쪽 반원 홈(지름 24). 홈은 화면 배경색으로 뚫린 것처럼 보이게 |
| 하단 | 출발 터미널, 게이트, 탑승 시작(추정). 값이 없으면 `미정`·`정보 없음`을 보조 글자색으로 |
| 결항 | 하단 값을 흐리게, 상단 상태를 결항 색으로 |

- 카드 전체가 하나의 버튼이다. VoiceOver는 "XX5701, 하네다에서 인천, 3일 후 10시 45분 출발, 45분 지연, 터미널 T3, 게이트 미정"처럼 한 문장으로 읽는다.
- 나머지 항공편 목록 행은 iOS 기본 목록 스타일을 쓴다.

## 6. 상세 화면 (S-06)

- iOS 기본 그룹 목록(`List` + `.insetGrouped`)을 쓴다.
- 맨 위에 **상태 배너**를 둔다. 내용은 다이내믹 아일랜드 펼침과 같고, 모양은 Live Activity 잠금 화면처럼 `brandNavy` 배경·흰 글자(지연·결항은 카드 위 상태 색)다. 가로로 꽉 채운다. (DS-13)
- 출발·도착은 각각 한 그룹.
- **머리 행**(출발·도착): 높이 52pt, `.headline`보다 조금 큰 18pt 굵게. 오른쪽 끝에 편집(연필) 아이콘 버튼 (DS-15).
- **정보 행**: 높이 48pt 고정. 이름은 왼쪽(`.subheadline` secondary), 값은 오른쪽 끝(`.title3` 굵게, 고정폭 숫자).
- 값의 왼쪽에 칩(`사용자 제보`, `변경`)과 변경 전 값(취소선)을 둔다. 칩 때문에 행 높이가 바뀌지 않게 한 줄로 배치한다.
- 큰 글자(접근성 크기)에서는 고정 높이 대신 최소 높이로 바꿔 글자가 잘리지 않게 한다.

## 6-1. 화면 모드 전환

- 설정의 화면 모드(시스템·라이트·다크)를 바꾸면 **화면 전체를 약 0.4초 크로스페이드**한다.
- SwiftUI의 `preferredColorScheme`만 바꾸면 즉시 바뀌므로, 창 전체에 전환 애니메이션을 입힌다. (M2 확정) 키 윈도의 `overrideUserInterfaceStyle`을 `UIView.transition(.transitionCrossDissolve, 0.4초)` 안에서 바꾼다.
- 탭 바·시트 등 시스템 요소도 함께 바뀐다.

## 8. 앱 아이콘

- 네이비 그라데이션 배경(`#0B2545` → `#1E4B8F`) 위에 아이콘의 **반 이상을 차지하는 굵은 흰색 'D'**.
- D의 굵은 선이 **활주로**다. 네이비 비행기가 D 곡선 부분의 중앙을 따라 **시계 방향**으로 달리고, 진행 방향(접선)을 바라본다.
- 비행기 뒤에는 **D 왼쪽 위 모서리**에서 시작해 윗변을 지나 곡선을 따라 꼬리까지 이어지는 **긴 점선**(활주로 중앙선 겸 이동 경로)을 네이비로 그린다.
- **왼쪽 세로선은 다른 부분보다 얇게**(24 → 18) 하고, D 바깥 윤곽은 유지한다.
- 점선 시작 지점(왼쪽 위 모서리)에 네이비 **출발점**(원)을 찍는다.
- 비행기 날개 끝은 D 선 안쪽에 들어온다. 특정 기종을 닮지 않은 단순한 실루엣으로 그린다.
- Icon Composer 레이어 구성 안: 배경 / D / 비행기·출발점·점선

**두 가지 버전** (같은 모양, 색만 다름)

| 버전 | iOS 모습 | 배경 | D (활주로) | 비행기·출발점·점선 |
|---|---|---|---|---|
| 다크 | 다크 모드 | 네이비 그라데이션 `#0B2545` → `#1E4B8F` | 흰색 | 네이비 `#0B2545` |
| 라이트 | 라이트(기본) 모드 | 아이보리 그라데이션 `#FBF7EF` → `#EFE6D4` | 네이비 `#0B2545` | 아이보리 `#FBF7EF` |

- 라이트 버전은 다크 버전의 **반전**이다. 모드가 바뀌어도 같은 앱으로 알아볼 수 있다. (검토 후보: 베이지+콘크리트 회색, 샌드+아스팔트, 미스트 블루 → 아이보리 반전으로 결정)
- 틴트·투명 모드는 M2에서 Icon Composer로 확인한다.
- 최종 아이콘은 M2에서 Icon Composer로 만든다. (iOS 26 다크·틴트 모드 대응) Claude가 레이어별 SVG(배경 / D / 비행기·출발점·점선)를 준비하고, Icon Composer 조립은 사용자가 한다. (VD-08)
- 미리보기의 아이콘은 방향을 보여 주는 시안이다.

## 9. 하지 않는 것

- 콘텐츠(카드·숫자)에 Liquid Glass·반투명 효과를 쓰지 않는다. 숫자 대비가 떨어진다.
- 유리 효과를 흉내 내는 블러 라이브러리를 넣지 않는다.
- 외부 글꼴, 사진 배경, 장식용 그림을 넣지 않는다.
