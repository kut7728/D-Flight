# 화면 흐름

## 1. 화면 목록

| ID | 화면 | 기능 | 형태 |
|---|---|---|---|
| S-01 | 로그인 | F-01 | 전체 화면 |
| S-02 | 알림 허용 안내 | F-05, F-06 | 전체 화면 (첫 실행 1회) |
| S-03 | 내 항공편 (탭 1) | F-03 | 탭 |
| S-04 | 항공편 등록 | F-02 | 아래에서 올라오는 시트 |
| S-05 | 직접 입력 등록 | F-02, F-07 | S-04 안에서 이동 |
| S-06 | 항공편 상세 | F-04, F-10 | 목록에서 이동 |
| S-07 | 정보 제보·수정 | F-07 | 시트 |
| S-08 | 지난 항공편 (탭 2) | F-03 | 탭 |
| S-09 | 설정 (탭 3) | F-01, F-06, F-09, F-11, F-12 | 탭 |
| S-10 | 공항 안내도 | F-04 | 앱 안 브라우저 |
| S-11 | 공지사항 목록·상세 | F-13 | 설정에서 이동 |
| S-12 | 강제 업데이트 | F-14 | 전체 화면 (닫기 없음) |
| — | 중요 공지 팝업 | F-13 | 알림 창 |

> Flutter로 비유하면 탭은 `BottomNavigationBar`, 시트는 `showModalBottomSheet`, 목록에서 이동은 `Navigator.push`다.

## 2. 첫 실행 흐름

```
앱 실행 (또는 백그라운드에서 돌아옴)
  └─ 최소 버전 확인 ── 낮음 ──▶ S-12 강제 업데이트 (여기서 멈춤)
        │ 통과 (확인 실패·오프라인도 통과)
        ▼
     로그인되어 있음? ── 예 ──▶ S-03 내 항공편 ──▶ 안 본 중요 공지가 있으면 팝업 (1회)
        │
        아니오
        ▼
     S-01 로그인 ──▶ (첫 로그인) S-02 알림 허용 안내 ──▶ S-03 내 항공편
```

- 최소 버전 확인은 **로그인 전에** 한다. 서버 확인에 실패하면 막지 않는다. (오프라인 공항에서 앱이 안 열리는 상황 방지)

- 알림을 거부해도 앱은 쓸 수 있다. 이후 S-03 상단에 '알림이 꺼져 있음' 안내를 보여 준다.

## 3. 탭 구조

```
┌────────────────────────────────────────────┐
│ [내 항공편]      [지난 항공편]      [설정]    │
└────────────────────────────────────────────┘
     │                 │                 │
     ▼                 ▼                 ▼
   S-03              S-08              S-09
     │ + 버튼          │ 항목 선택        ├─ 계정 삭제 확인
     ▼                 ▼                 └─ 언어·알림 설정
   S-04 등록         S-06 상세(읽기 전용)
     │ 결과 없음
     ▼
   S-05 직접 입력
     │
   S-03 항목 선택
     ▼
   S-06 상세 ──▶ S-07 제보·수정
             ├─▶ S-10 공항 안내도
             ├─▶ 지도 앱 (Apple / Google)
             └─▶ iOS 공유 시트
```

## 4. 앱 밖에서 들어오는 경로

| 출발점 | 도착 화면 |
|---|---|
| 변경·임박 알림 누름 | 해당 항공편 S-06 |
| 위젯 누름 | 해당 항공편 S-06 (항공편이 없으면 S-03) |
| Live Activity 누름 | 해당 항공편 S-06 |

로그아웃 상태에서 들어오면 S-01을 거친 뒤 이동한다.
