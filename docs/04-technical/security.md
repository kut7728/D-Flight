# 보안

이 저장소는 **공개 GitHub 저장소**다. 아래 항목은 설계이며, 구현·검증 전에는 완료로 표기하지 않는다.

## 1. 위협과 대응 요약

| 위협 | 대응 |
|---|---|
| 서비스 키 유출 | 앱에 넣지 않음. 서버만 Secret Manager에서 읽음 |
| 다른 사람 데이터 읽기·쓰기 | 로그인 필수 + Security Rules + 서버 함수 권한 검사 |
| 앱이 아닌 도구로 서버 함수 호출 | App Check 필수 |
| 공공 API 한도 소진 공격 | 사용자별 한도 + 일일 호출 한도 보호 |
| 장난 제보 | 형식 제한, 등록 사용자만 수정, 공항 데이터 항목 수정 불가, 수정 이력 |
| 로그로 개인정보 유출 | 토큰·이메일·편명+사용자 조합을 로그에 남기지 않음 |
| 비용 폭증 | 예산 알림 + 호출 한도. **전체 청구 상한은 보장되지 않음** |

## 2. 인증

- Firebase Auth: **Sign in with Apple**, **Google 로그인**
- 모든 서버 함수는 로그인 토큰을 확인한다.
- 계정 삭제 시 Apple 토큰 해지 → 서버 데이터 삭제 → Auth 사용자 삭제 ([API 명세](api-spec.md#10-deleteaccount))

## 3. App Check

- iOS 제공자: **App Attest** (기기가 진짜 앱인지 Apple이 증명)
- 서버 함수에 App Check를 **강제**한다. Firestore 읽기도 강제한다.
- 개발 중 시뮬레이터용 디버그 토큰은 **저장소·문서·로그에 기록하지 않는다.** 로컬 설정으로만 쓴다.

## 4. Firestore Security Rules

```
users/{uid}/**        읽기: 본인만         쓰기: 금지 (서버 함수만)
flights/{key}         읽기: 로그인 사용자   쓰기: 금지
flights/{key}/reportHistory/**   읽기·쓰기: 금지
system/**             읽기·쓰기: 금지
config/app           읽기: 누구나 (로그인 전 버전 확인용)   쓰기: 금지 (콘솔만)
notices/{id}          읽기: 누구나   쓰기: 금지 (콘솔만)
그 외                  읽기·쓰기: 금지
```

- `flights` 문서에는 사용자 정보를 넣지 않는다. (`trackerCount` 숫자만)
- 서버(Admin SDK)는 규칙을 거치지 않으므로 **서버 함수 코드에서 권한을 검사**한다.
- 규칙은 에뮬레이터 테스트로 검증한다. (06-testing)

## 5. 비밀 정보 관리

| 비밀 정보 | 보관 위치 | 저장소에 |
|---|---|---|
| 공공데이터포털 서비스 키 | Secret Manager | ❌ |
| APNs 인증 키 (.p8) | Firebase 콘솔에 업로드 | ❌ |
| App Check 디버그 토큰 | 개발자 로컬 | ❌ |
| `GoogleService-Info.plist` | 로컬 (`.gitignore`) | ❌ |

- `GoogleService-Info.plist`는 비밀 키가 아니며, 숨긴다고 보안이 보장되지 않는다. 실제 보호는 인증·Security Rules·App Check·호출 한도가 한다. 공개 저장소의 프로젝트 식별 노출을 줄이려고 커밋하지 않을 뿐이다.
- 이미 커밋된 비밀 정보는 파일 삭제가 아니라 **폐기·교체**한다.

## 6. 입력 검증

- 모든 서버 함수는 [API 명세](api-spec.md)의 형식으로 입력을 검증하고, 정의되지 않은 필드는 거부한다.
- 제보는 형식이 정해진 값만 받는다. 자유 텍스트는 받지 않는다.

## 7. 개인정보

| 수집 | 목적 | 보관 |
|---|---|---|
| 로그인 식별자, 이메일(Apple 숨김 가능) | 계정 | 계정 삭제 시까지 |
| 등록 항공편 | 기능 제공 | 사용자 삭제 시까지 |
| 푸시 토큰 | 알림 | 로그아웃·계정 삭제 시까지 |
| 제보 이력의 작성자 | 악용 확인 | 출발 + 30일, 계정 삭제 시 제거 |

- 예약번호, 좌석, 이름, 여권 정보는 **받지 않는다.**
- 개인정보 처리방침과 App Store 개인정보 라벨은 07-release에서 작성한다.

## 8. 테스트·목데이터

- 테스트·시연에는 가상 데이터만 쓴다. 실제 여행 정보와 실제 API 응답을 커밋하지 않는다.
- Mock 빌드는 Firebase를 초기화하지 않고 외부와 통신하지 않는다.
