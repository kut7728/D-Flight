## 결정 사항 (2026-10-12)

| # | 결정 |
|---|---|
| TD-01 | 앱·서버 코드를 **새로 작성**한다. 기존 코드는 참고만 한다. |
| TD-02 | 앱: **SwiftUI + @Observable MVVM** + Repository |
| TD-03 | 읽기는 앱이 Firestore 직접 구독, **쓰기는 모두 서버 함수 경유** |
| TD-04 | Firebase 지역 **도쿄 asia-northeast1** (Firestore 지역은 변경 불가) |
| TD-05 | 서버: **TypeScript**, Cloud Functions 2세대, Node.js 22 |
| TD-06 | 공공 API 조회: 등록 1회, D-3 전 하루 1회, D-3부터 1시간마다, **출발 6시간 전부터 15분마다** |
| TD-07 | 지난 항공편은 **사용자가 지울 때까지** 보관 |
| TD-08 | 제보 이력은 출발 30일 후 삭제, 계정 삭제 시 작성자 정보만 제거 |
| TD-09 | 같은 항공편은 **실제 운항 편명 기준 문서 하나**를 모든 사용자가 공유 |
| TD-10 | 시각은 UTC + 공항 시간대로 저장 |
| TD-11 | 공지사항(`notices`)·최소 버전(`config/app`)은 운영자가 Firebase 콘솔에서 입력. 앱은 로그인 없이 읽기만 |
| TD-12 | 화면 모드·공지 읽음 여부는 기기에만 저장 |

## 기본값으로 정한 항목 (확정, 운영하며 조정 가능)

| 항목 | 기본값 |
|---|---|
| 사용자별 한도 | 검색 시간당 30회, 다가오는 항공편 30편, 제보 하루 50회 |
| 시각 변경 알림 기준 | 5분 이상 바뀔 때 |

| 정리 함수 실행 시각 | 매일 04:00 (일본 시간) |
